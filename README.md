## 1. Official 152-Tile Set Breakdown

| Category | Tile Count | Key Rule |
| :--- | :--- | :--- |
| **Dots, Bams, Craks (`1–9` × 4)** | 108 tiles | `1 Bam` is the Bird tile. |
| **Winds (`N, E, W, S` × 4)** | 16 tiles | Suitless honors; `NEWS` singles never accept Jokers. |
| **Dragons (Red, Green, White × 4)** | 12 tiles | Red = Craks, Green = Bams, White ("Soap") = Dots **and** suitless Zero (`0`). |
| **Flowers (`F` × 8)** | 8 tiles | All 8 Flower/Season tiles (`1–4`) are 100% interchangeable and suitless. |
| **Jokers (`J` × 8)** | 8 tiles | Valid **only** in groups of **3+ identical tiles** (Pung, Kong, Quint, Sextet); **never** in Singles or Pairs, and **never** passed in the Charleston. |

## 2. Complete Charleston Sequence

1. **Round 1 (Mandatory):** `First Right (3)` → `First Across (3)` → `First Left (3, Blind Pass 1–3 allowed)`
2. **Stop Gate:** Any single player may stop after First Left; Round 2 requires unanimous agreement.
3. **Round 2 (Optional):** `Second Left (3)` → `Second Across (3)` → `Second Right (3, Blind Pass 1–3 allowed)`
4. **Courtesy Pass (Optional, Across Only):** Negotiate `0–3` tiles with opposite player (lowest offer governs; no blind pass).
